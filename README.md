- 🔁 Láminas repetidas
- 🤝 Intercambios inteligentes
- 💰 Láminas para venta
- 📊 Progreso por país

---

## 🚀 Funcionalidades principales

### 📘 Álbum
- Visual tipo grilla (1–20 por equipo)
- Marcar lámina como conseguida con un clic
- Seguimiento automático de progreso

---

### 🔁 Repetidas
- Registro por equipo y número
- Manejo de múltiples copias (contador)
- Clasificación:
  - 🔁 Intercambio
  - 💰 Venta
- Visual organizado igual que el álbum

---

### 🤝 Intercambio inteligente
- Detecta automáticamente láminas faltantes que tienes repetidas
- Filtra solo láminas disponibles para intercambio
- Permite ejecutar intercambio:
  - ✅ Descuenta la repetida
  - ✅ Marca la lámina como conseguida

---

### 📊 Dashboard
- Porcentaje de avance por cada país
- Visualización del progreso del álbum

---

### 💰 Valor estimado
- Calcula automáticamente el valor de las láminas en venta
- Configurable desde el código
